Lab 05

Published on April 5, 2026 by Joshua Oluwajana

Lab 5 taught me a lot about responsive design in web development. I learned that a good webpage should work on any screen size, not just on a desktop. Using flexbox made it easier to control how elements are arranged on the page.

What I Learned

  1. How to create a single column mobile layout using CSS flexbox
  2. How to use a media query to switch to a multi-column desktop layout
  3. How to add named anchor links so users can navigate between blog posts

I learned a lot from:

  • W3Schools
  • Mozilla
  • Professor Noone's Layout Demo
